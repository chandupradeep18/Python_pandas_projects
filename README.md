[# Python Pandas Projects

A collection of Python Pandas exercises and real-world data analysis projects developed to learn and practice data manipulation, data cleaning, data filtering, exploratory data analysis (EDA), and ETL workflows using Python.

This repository demonstrates practical applications of the **Pandas library** through hands-on exercises and datasets from different domains, including e-commerce, global development, real estate, sales, and weather data.

## 📌 Repository Overview

The repository is organized into two main categories:

- **Pandas Fundamentals:** Practical exercises covering essential Pandas operations and DataFrame manipulation.
- **Data Analysis Projects:** Real-world datasets used to explore, clean, manipulate, and analyze data.

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.8 or above
- pip package manager
- Jupyter Notebook or JupyterLab

### Step 1: Clone the Repository

```bash
git clone https://github.com/chandupradeep18/Python_pandas_projects.git
```

### Step 2: Navigate to the Project Directory

```bash
cd Python_pandas_projects
```

### Step 3: Create a Virtual Environment (Optional)

```bash
python -m venv .venv
```

Activate the environment:

**Windows:**
```bash
.venv\Scripts\activate
```

**Linux / macOS:**
```bash
source .venv/bin/activate
```

### Step 4: Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 5: Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any `.ipynb` file and execute the notebook cells.
